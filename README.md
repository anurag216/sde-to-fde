# SDE → FDE

A career-first, hands-on software-engineering learning platform built initially for one primary user: an experienced QA/SDET/automation engineer transitioning toward stronger software engineering, backend/platform engineering, AI engineering, and Forward Deployed Engineering.

## North star

This project succeeds if the learner becomes measurably better at **understanding, designing, implementing, debugging, and explaining real software systems**. Turning it into a commercial product is secondary.

## Learning loop

**Problem → attempt → failure → hint → discovery → explanation → repetition → mastery**

The platform should recognize practical engineering experience, avoid forcing a beginner curriculum, and target the gaps that matter for the learner's next role.

## Alpha scope

- Practical diagnostic assessment
- Skill graph and mastery profile
- Personalized roadmap shell
- Scenario-based engineering missions
- Progressive tutor assistance model
- XP/progression tied to demonstrated competence
- Local-first progress tracking

The first version intentionally excludes payments, multi-tenancy, elaborate authentication, mobile apps, and production infrastructure.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Current status

The first alpha is intentionally small. It provides the diagnostic/progression shell and persists attempts locally. Real sandboxed code execution and AI evaluation are the next implementation step; the UI does not pretend those capabilities are already wired.
