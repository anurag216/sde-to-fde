# Alpha roadmap

## Alpha 0.1 — Diagnostic shell

Goal: create a place where the primary learner can begin the journey instead of doing the journey in chat.

- [x] Career-first dashboard
- [x] Skill graph taxonomy
- [x] Mixed diagnostic challenge schema
- [x] Local persistence
- [x] Objective scoring where deterministic
- [x] Free-response/coding evidence capture without fake scoring

## Alpha 0.2 — Real evaluator

- [ ] Sandboxed execution for TypeScript/JavaScript and Python challenge code
- [ ] Test-case result UI
- [ ] AI evaluation for free-response/design answers
- [ ] Progressive hints with assistance-level tracking
- [ ] Misconception tags
- [ ] Attempt history

## Alpha 0.3 — Evidence-backed baseline

- [ ] Generate skill profile from diagnostic evidence
- [ ] Confidence score separate from mastery
- [ ] Identify formal-vocabulary gaps vs implementation gaps
- [ ] Generate first 4-week personalized plan
- [ ] Recommend initial career-path weighting: backend/platform vs AI vs FDE

## Alpha 0.4 — Mission engine

- [ ] Multi-step scenario missions
- [ ] Introduce failures after initial implementation
- [ ] Cross-skill missions (e.g. queue + idempotency + DB + observability)
- [ ] Boss challenges requiring design + code + explanation
- [ ] Delayed concept resurfacing

## Do not build yet

- payments
- multi-tenant organizations
- sophisticated authentication
- native mobile apps
- social/community features
- elaborate branding
- microservices

We should earn complexity only after the career-learning loop proves useful to the primary learner.
